# G319 — modem RX submit recovery plus cumulative GNSS/Enforcing OTA

The G319 kernel (Git `d1357cc1a`) adds USB HSIC RX-URB *submission* retry for transient `-ENOMEM`/`-EAGAIN`. The retry re-submits only the URB and never copies the prior modem IPC packet twice. Existing `fmt_stats` now exports privacy-safe `rx_submit_retries` and `rx_submit_errors`, in addition to FMT RX/TX, parse and runtime power counters. Handles suspend, disconnect and module unload by canceling the worker. All other SIPC4 framing and OEM voice route logic is unchanged. Full ARM32 zImage+DTBs compiled successfully. This is a robustness patch; whether it addresses the previously observed 120-second outgoing SMS ACK timeout has **not** been verified.

The standalone G319 BOOT is built with the same product reference ramdisk, SM-T311 appended DTB, Android 11 BOOT header v0 and same arguments as G316. The G316 policy/GPS system changes remain exactly six files, including Android init `namespace mnt`, time injection, native satellite status fallback and SELinux changes. The combined G319 OTA updates these six files first, verifies their target SHA256 values, and only then installs the G319 BOOT, which also checks those six SHA256 values independently inside the flash step. The script compares current physical G301 BOOT checksum before writing, verifies the new BOOT checksum afterward, and does not modify recovery/EFS/userdata. This is not a power-loss-atomic operation.

To construct: `python3 device/samsung/lt013g/tools/build_g319_combined_twrp_ota.py`; to run signed shell fixture tests: `python3 device/samsung/lt013g/tools/test_g319_combined_offline.py`. All fixture tests and signed ZIP CRC have passed OFFLINE. No reboot or TWRP installation occurred as part of this milestone. **G319 supersedes G318** as the latest candidate, not a required second flash.
