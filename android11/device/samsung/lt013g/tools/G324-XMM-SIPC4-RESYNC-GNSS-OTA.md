# Samsung SM-T311 G324 — XMM6262 SIPC4 RX resynchronization

Kernel source `4048bfce9` fixes a receive-parser error path in `drivers/misc/samsung-tab3-xmm6262-runtime.c`. Previously, the parser returned `-EBADMSG` and the caller discarded all remaining bytes from the current USB URB when it saw a non-START byte, an invalid frame header, or a bad end marker. If another complete frame followed in the same URB, it was lost. Now malformed framing consumes only invalid bytes/frames and scans for the next 0x7f START; a START encountered in place of a corrupted END is retained as the next frame's delimiter. The number of errors is counted using the existing privacy-safe `fmt_parse_errors` counter. Valid SIPC4 framing/lengths, port numbers, Samsung RIL and audio routes remain unchanged.

A new host test, `kernel/tools/test_sm_t311_xmm_fmt_resync.py`, **extracts and compiles the actual kernel `xmm_parser_reset`, `xmm_parser_header_done`, and `xmm_parse_stream` functions** into mock SKB equivalents with `-Wall -Wextra -Werror`. Tests PASS: two frames in one USB transfer; leading/inter-frame padding; invalid header followed by valid frame; malformed terminator followed by START across two URBs; and a clean frame split across two URBs. This proves parser behavior under these mock inputs, not modem hardware interoperability. Full Linux 6.12.112 ARM32 `make zImage dtbs` PASS.

The signed G324 cumulative TWRP ZIP contains the new G324 BOOT plus six unchanged G323 system files (GPS HAL with independent GNSS SV callbacks, GNSS UTC assistance/receiver XML, GPS init namespace, SELinux policy). All six physical original G301 SYSTEM hashes and original full BOOT are preconditions; six new SYSTEM hashes must match before BOOT is written last. Correct system-as-root recovery paths and original SELinux inode labels are retained without unsupported recovery relabel. No recovery/EFS/userdata changes. Host signed updater-script failure tests PASS, but actual TWRP and Enforcing boot have NOT been tested; this update is not power-loss atomic. G324 replaces G323 as the newest candidate and does not need the older ZIP installed first.

The original user SMS was confirmed delivered but Samsung proprietary RIL timed out after 120 seconds and Android reported failure. This receive-parser fix could help preserve a response frame but **does not establish that this was the cause or that SMS acknowledgment now works**. Require user-led SMS/call tests with privacy-safe `fmt_stats` before claiming success. GPS+GLONASS radio signal was observed, but automotive fix and the G323+ callback/time-injection improvements remain unverified on the live G301.
