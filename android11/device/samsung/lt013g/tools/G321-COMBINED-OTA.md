# SM-T311 G321 — RX retry / suspend ordering and cumulative GNSS Enforcing OTA

Kernel commit `933a77c12` fixes a suspend-time USB HSIC race in the XMM6262 modem RX path. On power management suspend, the driver first marks the pipe suspended, drains both receive submission retry and receive buffer allocation retry workers, and then synchronously kills the active URB. The buffer-copy retry worker now checks that the pipe is present, not suspended and its completed URB status was successful before accessing the buffer. This avoids resurrecting/copying an obsolete modem IPC frame while the HSIC link is suspended.

The patch builds Linux 6.12.112 ARM32 `zImage dtbs` without errors. It is a source-level reliability change; the original SMS ACK timeout, actual modem suspend/resume, and phone audio acceptance are **not** claimed resolved without on-device tests. OEM SIPC4 format, RIL behavior, radio power routing and audio routes are unchanged.

BOOT G321 preserves the original Android 11 product ramdisk and SM-T311 DTB, uses an Android boot header v0, and continues to omit the conflicting `androidboot.selinux=permissive` kernel argument. The signed G321 TWRP update includes six previously compiled GNSS+SELinux+GPS init namespace files and this new BOOT. The current physical G301 BOOT checksum and all six old SYSTEM file hashes are verified before writes, new SYSTEM hashes checked before BOOT, BOOT written last and hash-verified. The TWRP path layout is system-as-root: correct file_getprop path `/system/system/build.prop` and GNSS files `/system/system/vendor/...` in recovery.

Build: `python3 device/samsung/lt013g/tools/build_g321_combined_twrp_ota.py`. Offline isolated signed shell test: `python3 device/samsung/lt013g/tools/test_g321_combined_offline.py`. Offline PASS is **not** power-loss atomicity or a real TWRP boot/install test. Do not flash unattended without verified recovery/rescue control. G321 supersedes G320 as the recommended candidate, earlier ZIPs not required.
