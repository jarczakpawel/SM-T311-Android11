# Samsung SM-T311 G332 — framework/local SUPL connection serialization

Production GPS proxy audit after G331 found two real software defects. First, framework `data_conn_open` and `data_conn_open_with_apn_ip_type` wrote `g_v398_framework_data_open=1` before receiving a return code from legacy Broadcom, so a failed `OPEN` remained marked as connected. Second, framework `OPEN`, `CLOSED` and `FAILED` commands did not take the same `g_v398_link_lock` introduced by G330 for local asynchronous `OPEN/CLOSED` workers. Consequently a delayed framework `CLOSED` could race with a newly opened private SUPL connection, and a new framework `OPEN` could overlap a pending private `CLOSED`.

G332 centralizes both framework open overloads into `v332_framework_data_conn_open`. It locks the shared link gate for the complete legacy CP command and status update. When a local SUPL connection is actually active it suppresses redundant framework commands. If an earlier private session has `g_v398_pending_close`, it drains that `CLOSED` first; on failure it blocks a duplicate `OPEN`, preserving pending cleanup and returning the actual error. Framework-connected state becomes true only after successful `OPEN`, and a vendor error resets the pending framework-request state. A generation superseded during `OPEN` triggers a matching `CLOSED` before unlocking. Framework `data_conn_closed`/`failed` use the same gate and cannot terminate active local SUPL. Positive/negative CP error codes remain preserved; no fake SUPL success. Older NTP/UTC, NMEA GPS+GLONASS, GSV/GSA, RMC week corrections, XMM6262/RIL/voice paths are unchanged.

`tools/test_g332_framework_supl_state.py` extracts and compiles EXACT source C functions, mocks only CP commands and state mutex, uses cc `-std=gnu11 -O2 -Wall -Wextra -Werror -pthread`; 10 PASS: classic OPEN, error OPEN state reset, local-open suppression, stale CLOSED before framework OPEN, failed CLOSED prevents new OPEN, typed APN overload, local suppression of CLOSED/FAILED, framework CLOSED cleanup, framework FAILED negative rc, superseded-generation OPEN -> matching CLOSED. Earlier 8 real-C G331 local SUPL workers tests PASS. No network, tablet GPS receiver or SMS used.

Full Android 11 `m gps.default.lt013g.v195 target-files-package -j3` PASS. New `gps.default.so` SHA256 `7ff5b99da268c8cc23fd3d491e842b60f30958e2289f199e74f7856cfd06236c`. G332 signed cumulative G301->G332 TWRP ZIP holds six files GNSS/SELinux (one new GPS HAL, five as G331), and exact identical G327 BOOT SHA `9487424414439edf4dd00bf4169bcd684572cc4abe6690af9589632205666436`. Offline signed-script preflight, damage rejection, BOOT-last and idempotence tests PASS; not physical TWRP execution or power-loss atomicity. No EFS, RECOVERY or userdata writes intended.
