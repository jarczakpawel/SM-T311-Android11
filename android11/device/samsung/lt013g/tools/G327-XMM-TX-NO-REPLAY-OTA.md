# SM-T311 G327 — prevent queued modem IPC replay on HSIC reconnect

Kernel source Git `4c02b9c9b` closes a source-proven stale-TX bug: the previous XMM6262 runtime disconnect stopped USB transfers and canceled TX work but retained pending FMT and RAW frame queues. A new CMD interface probe set runtime_connected=true and scheduled tx_work, potentially retransmitting old IPC requests (SMS, calls or other modem commands) from a disconnected session. Stock Samsung modem_link_device_hsic.c purges its FMT/RAW TX queues on entering the BOOT state. The new kernel flushes BOTH pending queues **after** synchronously stopping tx_work and killing in-flight TX URBs, and before any newly established USB IPC session can reuse them.

New irq-safe tx_gate_lock serializes enqueue from RIL userspace **and netdev atomic context** with transitions of runtime_connected. After the gate closes, late frame admission is rejected -ENODEV. Reopening permits only fresh requests. FMT/SIPC4 framing, ACK codes, phone/audio routing and non-reconnect TX semantics remain unchanged; no SMS is sent or silently reported successful.

The actual C function xmm_enqueue_tx is compiled into a host regression executable by kernel/tools/test_sm_t311_xmm_tx_session_gate.py, with four PASS scenarios: FMT+RAW accepted in current session, new entries rejected after shutdown, two previous queues empty before a new session, fresh requests accepted after reopen. The test asserts ordering in actual disconnect source and lock initialization. Existing 14 original-Samsung-parity SIPC4 TX/RX tests PASS. Linux6.12.112 ARM32 full zImage dtbs build PASS, new BOOT v0 retains existing Android11 ramdisk and exact SM-T311 DTB. Physical SMS ACK and modem reconnect are NOT yet proven.

This signed cumulative G301->G327 installer includes **six** G323 GNSS/SELinux system payloads (ON_DEMAND_TIME/NTP, Broadcom gps.xml IgnoreJniTime, GPS+GLONASS NMEA GSV/GSA native fallback and text-independent satellite callback, RMC outward rollover date fix, SUPL/DNS config, GPS init namespace mnt and compiled Enforcing policy) and new G327 BOOT. Previous packages are not prerequisites. Preconditions require exact source G301 six SYSTEM hashes, full original BOOT checksum and correct TWRP system-as-root paths; update six SYSTEM first, verify all, BOOT last, verify BOOT. Older recovery SELinux policy lacks new GPS executable type; preexisting inode security labels are preserved through O_TRUNC extraction, with no explicit relabel. No RECOVERY/EFS/DATA writes intended. Host signed-shell failure tests pass; installation is NOT power-loss atomic and physical TWRP/Enforcing/GNSS validation is required.
